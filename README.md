# shelfie-app.ca

Marketing and support site for **Shelfie**, the social beauty app by Stackset Technologies Inc. Static HTML + CSS with GSAP / ScrollTrigger / Lenis / SplitType (vendored). No build step.

Pages: home · features · security · about · support · privacy · terms · 404. Plus `robots.txt`, `sitemap.xml`, `.well-known/security.txt`.

See **DEPLOY.md** for GitHub Pages + DNS.
